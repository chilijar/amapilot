### P0-1 · SDK 二进制提交进公开仓库 —— 违反高德协议，最明确的一处【已实施修复，2026-11-19】

`app/libs/*.jar`（38MB）与 `app/src/main/jniLibs/arm64-v8a/` 7 个 .so 已
`git add -f` 入库。服务协议：

- **2.2** 将"开发包"明确列入归高德所有的"相关内容"
- **4.12.8**："您对本服务的使用不能使得您或任何其他人可以下载或获得任何相关内容"
- **4.12.7**：不得复制、传播本服务及相关内容的全部或部分

公开仓库放 SDK 本体 = 任何人 clone 即可获得完整开发包，直接命中
4.12.8。**条款文本上的明确违约，非模糊地带**。v0.16.0 为 16KB 对齐
入库是正确的工程决策，但需要补救。

**修复实施（2026-11-19，已落地）**：

- `git rm --cached` 移除全部 8 个二进制的 git 跟踪（磁盘保留，构建不受影响）；
  `.gitignore` 删除 `!app/src/main/jniLibs/**/*.so` 例外并新增
  `app/libs/AMap3DMap*.jar` 规则（全局 `*.so` 规则回归生效）
- 新增 `scripts/fetch-amap-sdk.sh`：官网直链拉取一体包 zip（URL 匿名可用，
  官方元数据接口 `getSdkJson` 提供 md5/版本），zip+文件级双重 md5 pin 锁
  版本，幂等（就绪即跳过）、`--force` 升级、端到端校验通过（落位文件与
  原入库二进制 bit 一致，构建产物零变化）
- `app/build.gradle.kts`：jar 引用改 `AMap3DMap*.jar` glob（升级不动
  build 文件），缺失/多版本时显式 `GradleException` 报错指引
- CI：新增 composite action `.github/actions/setup-sdk`（actions/cache
  按 zip md5 作 key + 幂等脚本），`ci.yml`/`release.yml` 均接线

### P0-2 · GPL-3.0 × 专有 SDK 的许可冲突

- GPLv3 §5(c)/§6：分发整个作品（APK/AAB）须整体以 GPL 授出
- 高德 SDK 专有且 7.2/7.3 禁止再许可、转授权 → 组合 APK 严格读法下两头不合规
- §1 "System Libraries" 例外不适用（高德 SDK 非 OS 组件、随 app 打包分发）

项目尚无外部贡献者，版权人唯一，随时有权加例外。两条路：

1. **GPLv3 §7 附加许可（推荐，保留 copyleft 初衷）**：在 LICENSE/README
   追加 linking exception——"作为本作品的版权持有人，依据 GPLv3 §7
   授予附加许可：允许将本作品与高德地图 SDK 及其自带的任何第三方库
   链接、组合并分发"。即 Classpath exception 用法，先例成熟。
   将来接受 PR 前应加 DCO 声明确认贡献者接受此例外。
2. **改主许可 Apache-2.0**：商业 SDK 生态常见选择（OsmAnd 纯 GPLv3
   是因为它用自由地图引擎）。损失 copyleft，换最大兼容。

### P1-3 · 高德协议 3.4：车载场景限制（命中产品核心）

> "除非我们专门授予您明确清晰的书面许可，您不得将本服务及相关内容
> 应用于车载场景（包括但不限于……用于投射至车载设备的应用等）"

Android Auto 投射是本项目核心场景，严格文本命中。该条无个人/非商业
豁免（3.1 的个人免费额度是独立条款）。**建议**：向高德提工单咨询 AA
场景许可定位，书面答复存档 `docs/`；在此之前属"接受风险继续"的
决策项，技术无法消除。

## 附录 · 换用百度 SDK 的评估（已否决）

背景：评估换百度地图 SDK 能否绕开高德限制。结论：**不能**——车载/再分发/专有性三大
限制两家同构，且百度对本项目更不利。

| 限制点 | 高德 | 百度 |
|---|---|---|
| 车载场景 | 3.4 明确包含"投射至车载设备的应用" | 2.3 商业目的排除车载，集成形态需另行书面授权 |
| SDK 再分发 | 4.12.8 禁使人获得开发包 | 3.3.3/3.3.4 同构（禁下载/复制/公开展示） |
| 专有性（GPL 冲突根源） | 7.2/7.3 禁再许可 | 6.4 措辞更绝对 |

百度额外劝退点：11.6 境外使用需书面通知（AA 用户恰在海外）；商用授权仅限公司主体；
审图号义务更重；导航层按高德 API 深度耦合，换 SDK = 全部重写。唯一文本差异是百度未点名
"投射"，但"车载场景"为兜底概念，抗辩空间不成立。
